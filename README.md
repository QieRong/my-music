# My Music

My Music 是一个基于 HBuilderX、uni-app 和 Vue 3 的深色音乐播放器项目。它优先处理本机音乐的轻量索引，并只在用户主动导入、启用并确认的前提下扩展自定义音源能力。

> 项目仍在开发中。请以本 README 的能力边界为准，不要将其视为音乐内容服务、版权授权平台或通用下载器。

## 项目原则

- 隐私优先：本地音乐仅建立轻量元数据索引，不保存真实路径、`content URI`、可播放地址或文件二进制。
- 用户主动：不会静默扫描 H5 用户目录，不内置、自动导入、自动启用或推荐第三方音源。
- 能力分阶段开放：未完成或未授权的能力保持关闭，不以 UI 状态模拟冒充真实能力。
- 原创实现：不包含第三方音乐平台源码、品牌标识、专有 UI、音乐文件、歌词、封面或音源脚本。

## 已支持的能力边界

### 本地音乐索引

- H5 仅通过用户主动选择文件建立索引，支持 `mp3`、`m4a`、`wav`、`flac`、`aac`、`ogg` 元数据。
- Android 端只在用户点击扫描后申请音频权限，并通过 MediaStore 读取白名单元数据。
- 索引用于搜索、列表和播放器状态展示，不代表可以播放用户本地文件。

### 用户自定义音源

- 音源必须由用户从本地主动导入；项目不提供默认音源或第三方音源列表。
- 导入后默认禁用。执行前必须由用户启用，并确认当前脚本版本的运行许可。
- 已开放的 H5 能力仅按音源声明分别提供搜索、播放或下载入口；未声明的能力不可用。

### H5 下载与缓存

- 仅适用于用户主动导入、已启用、声明 `download` 且已确认当前脚本版本的音源。
- 每次下载前都要求用户确认版权与责任提示；只缓存完整下载成功的音频 Blob 和最小脱敏元数据。
- 不提供 App 下载、后台下载、断点续传、自动下载、默认下载推荐、歌词缓存或封面缓存。

## 运行方式

1. 使用 HBuilderX 打开项目根目录。
2. 选择 H5 运行或发行流程进行预览。
3. 按页面提示先阅读免责声明，再按需扫描本地音乐或导入自己的音源。

本项目当前没有 `package.json`，不要默认执行 `npm install` 或 `npm run build`。H5 构建和预览依赖 HBuilderX 的 uni-app 运行环境。
