# My Music

My Music 是一个基于 **HBuilderX、uni-app 和 Vue 3** 开发的深色音乐播放器项目，主要用于学习和实践跨平台前端开发、本地音乐信息管理、播放器界面设计、浏览器存储以及 Android 系统媒体能力。

> **本项目仍在开发中，仅供个人学习、技术研究与交流使用。**
>
> 本项目不提供任何音乐内容、版权授权、商业音乐服务或第三方音乐平台接口。项目仓库中的功能说明仅代表软件本身的技术实现范围，不代表开发者拥有或授予任何音乐作品及其他第三方内容的使用权。

---

## 项目原则

* **隐私优先**：本地音乐仅建立轻量元数据索引，不主动保存不必要的文件信息或音频文件副本。
* **用户主动**：涉及本地文件、系统媒体权限等操作时，仅在用户主动执行相应操作后处理。
* **最小权限**：仅在功能确有需要时申请相关系统权限，并尽可能减少数据读取范围。
* **能力分阶段开放**：尚未完成、未经验证或当前平台不支持的能力保持关闭，不通过界面状态模拟尚不存在的功能。
* **原创实现**：仓库不包含第三方音乐平台源码、品牌标识、专有界面、音乐文件、歌词、专辑封面或艺人素材。
* **学习用途**：项目主要用于 uni-app、Vue 3、H5、Android MediaStore、IndexedDB 等相关技术的学习与实践。

## 已支持的能力边界

### 本地音乐索引

H5 端仅在用户主动选择本地文件后建立音乐信息索引，目前主要支持：

* `mp3`
* `m4a`
* `wav`
* `flac`
* `aac`
* `ogg`

索引内容主要用于：

* 音乐列表展示
* 本地搜索
* 基础信息展示
* 播放器状态管理
* 本地数据管理实验

索引本身不代表程序一定能够直接播放对应文件，实际能力受到浏览器、操作系统、文件格式以及运行环境限制。

---

### Android 本地媒体扫描

Android 端使用系统提供的 **MediaStore** 能力读取设备中的媒体信息。

程序遵循以下原则：

1. 仅在用户主动执行扫描操作后申请必要权限。
2. 仅读取功能需要的媒体元数据。
3. 不主动上传用户的本地音乐信息。
4. 不在后台静默扫描设备媒体库。
5. 用户拒绝权限后，不绕过系统授权继续访问。
6. 实际行为遵循当前 Android 系统的权限模型。

不同 Android 版本可能存在权限名称、授权方式及 MediaStore 行为差异，因此部分功能仍需要更多真机测试。

---

### 本地数据与缓存

项目中的本地存储主要用于保存必要的软件状态和音乐索引信息。

设计目标包括：

* 尽量减少持久化数据量。
* 避免保存没有必要的敏感文件信息。
* 支持清理本地缓存。
* 对重复数据进行必要的去重处理。
* 对浏览器存储不足、数据异常等情况进行错误处理。
* 不将缓存机制作为音乐内容长期保存或传播工具。

H5 环境下的存储行为还会受到浏览器实现、隐私模式、设备剩余空间以及浏览器配额机制影响。

## 运行方式

### H5

1. 使用 **HBuilderX** 打开项目根目录。
2. 选择 H5 运行或发行流程。
3. 在浏览器中打开项目。
4. 阅读页面中的使用说明。
5. 根据需要选择本地音乐文件并建立索引。
6. 测试完成后，可在设置或浏览器相关页面清理本地数据。

### Android

Android 相关功能需要使用 HBuilderX 对应的 App 运行环境或真机调试环境。

由于 Android 不同系统版本的媒体权限存在差异，建议优先使用真实设备验证以下场景：

* 首次授权
* 正常授权
* 拒绝授权
* 重复拒绝
* 无音乐文件
* 大量音乐文件
* 文件被删除后的索引状态
* 应用重新启动
* 系统升级后的权限状态
